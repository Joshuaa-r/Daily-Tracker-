# Daily-Tracker-
This is an app where you can track all your daily and weekly tasks and also you can upload all your google calander events as well 

## Workspace
This repository now includes a simple workspace page where you can add projects and upload project files from your computer.

### How to use
1. Open `/home/runner/work/Daily-Tracker-/Daily-Tracker-/index.html` in a browser.
2. Enter a project name and optionally a short description.
3. Choose one or more files and click **Upload Project**.
4. Your uploaded project entries appear in the workspace list.
