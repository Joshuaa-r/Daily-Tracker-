Import Google Calendar

A web page can’t sign in to Google for you, so import an export file instead. On the Google Calendar website (use Chrome’s “Desktop site”), open Settings, then Import & export, then Export. Unzip the download and choose the .ics file for your calendar. Events from the past 2 weeks and the next 60 days are loaded.
